Model & architecture

u̇ = u (−γ + ρv − α)     v̇ = v ((1 − u)/σ − α − β)

u is the wage share, v the employment rate. The interior equilibrium is v* = (α+γ)/ρ and u* = 1 − σ(α+β). Orbits are closed cycles; the conserved quantity H(u,v) is tracked to report numerical drift.

The solver is a plain Python module (core/goodwin.py). In browser mode it runs in Pyodide (CPython compiled to WebAssembly) in a Web Worker; in server mode the identical file runs behind FastAPI. The front end only talks to api.js.
